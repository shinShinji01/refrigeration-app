# Реальные данные для проектирования

Заполни: 2–3 настоящие холодильные установки со всем составом.
Формат свободный — таблица, список, фото Excel.

Что важно увидеть:

- сколько сборочных узлов в установке
- сколько деталей в узле (порядок величины)
- сколько групп изоляции и кусков в группе
- реальные формы кусков: прямоугольники / сложные контуры, какие вырезы
- сколько версий набора изоляции накапливается за год
